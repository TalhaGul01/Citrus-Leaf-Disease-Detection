PROJECT INFORMATION

About the System

This academic prototype classifies Kinnow citrus leaf images using image preprocessing, handcrafted color and texture features, and a Random Forest machine learning classifier. The feature vector contains 8,158 values: 48 color-histogram features, 10 LBP features, and 8,100 HOG features.
